Política de privacidade – Câmeras Backup

Atualizada em 7 de novembro de 2026.

O que o app faz

O Câmeras Backup roda apenas no computador do proprietário e usa a Google Drive API para enviar arquivos (vídeos das câmeras e backups de configuração) para uma pasta do Google Drive da própria conta que autorizou o acesso.

Dados acessados

O app só cria, lista e apaga arquivos dentro da pasta de backup escolhida, para manter a retenção configurada. Ele não lê outros arquivos do Drive para outros fins.

Compartilhamento

Nenhum dado é enviado a terceiros, vendido ou usado para publicidade. O token de acesso fica guardado apenas no computador do proprietário.

Revogar acesso

O acesso pode ser revogado a qualquer momento em myaccount.google.com/permissions.
